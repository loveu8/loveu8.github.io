首輪未找到可直接對應 P-0001 的建設承諾，因此按規模、服務範圍與正文用途選擇。各工作包的成本歸入所屬計畫並核對是否重疊。

| 清冊 ID | 項目 | 財源查核重點 |

| PR-02 | Logan and Gold Coast Faster Rail | 核對州與聯邦分攤、分包預算及支出。 |
| PR-03 | The Wave | 按期查資金狀態，特別是二期建設資金條件。 |
| PR-04 | Brisbane Metro | 查建設、車輛及常態營運成本。 |
| PR-05 | Brisbane Metro 擴建 | 核對商業論證資金與各走廊建設承諾。 |
| PR-06 | 新版公車路網 | 查營運增支與州、市分攤，核對與 Metro 的重疊項。 |
| PR-07 | 50 分票價 | 查票收與州補助，以及交通營運經費的列報範圍。 |
| PR-08 | 新列車製造計畫 | 核對採購、製造廠、維修基地及長期維護的範圍。 |
| PR-09 | Coomera Connector 第一期 | 查州與聯邦分攤及北、中、南段支出。 |
